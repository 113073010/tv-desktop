## 2026-11-01 ~ 11-02 · v1.0.0：从逆向到三 TAB

最早的起点不是写代码，是拆电视。乐视原生桌面 `com.stv.launcher` 有一套插件机制——
插件 APK 不放桌面图标，而是被桌面当作一个 Tab 页用 DexClassLoader 加载。

- 逆向 `com.stv.launcher`，找到 `ILePluginCreateApi`、`SCREEN_INFO` 表、`meta-data` 声明方式
- 先做了三个 TAB：**新闻**（7 分类纯文字 + 百度 TTS 朗读）、**直播**（DIYP 频道表 + IJK 播放器）、
  **豆瓣荐片**（海报墙，交给 TVBox 播放）
- 写了 `restore.sh` / `check.sh` / `clear.sh` 恢复工具和数据库模板
- 电台和股票还没加；TTS 还是百度在线语音

> 踩坑记录：`docs/DEVICE.md` 里「电视 shell 的限制」和「复现探测」两节就是这时候攒下来的。

## 2026-11-03 · 密集修复日

这天几乎全在调两个东西：股票的 K 线交互和新闻的 TTS 朗读。

### 股票侧

- 国际 / 国内 / 自选统一为近一年日 K，详情区按「确定」切当日分时
- 美股时间统一换算成北京时间（含夏令时）
- 调试日志加 512KB 上限，避免 `/sdcard` 无限增长
- 左右键打通列表与右侧详情；油价按天缓存，切 TAB 不重抓

### 新闻侧（这天改了很多版）

| 版本 | 改了什么 |
|---|---|
| 1.0.10 | 小数点不再被当断句符（`3.5` 不再读成「三五」），加了离线回归测试 |
| 1.0.11 | 设置面板加引擎选项（百度 / Edge）、音色、语速；`voice_name` 按名字找回音色 |
| 1.0.14 | 接入微软 Edge TTS（通过 OpenWrt 局域网桥，绕过电视 TLS 指纹 403） |
| 1.0.15 | 全文播完停 3 秒无按键自动接下一条全文 |
| 1.0.16 | 桥地址从 `192.168.1.10` 改成 iStoreOS 网关 `192.168.1.22:8123` |

> 小数点断句那个坑排查了很久：短文本直接送 Edge 桥读得好好的，只有长文才复现。
> 最后用 `tcpdump` 抓电视发出的 HTTP 请求才发现是 `splitChunks()` 把 ASCII `.` 当断句符，
> 切点正好落在 `3.` 和 `5` 之间。详见 `DEVICE.md`。

### 其他

- live 插件补回 `PlayerKit.java`，构建脚本改成按脚本位置取工程
- `restore.sh` 去掉换库前的 sleep 窗口——桌面被 `kill -9` 后 1 秒就被系统拉起，
  留了 sleep 它会用旧页缓存把刚写进去的 MD5 刷回去

## 2026-11-13 · v3.1.0：独立 APK

之前所有产物都是桌面插件，必须依赖 `com.stv.launcher` 才能跑。
这天加了一层 `app-host`，把插件改成普通 APK：

- **news-app.apk**（`com.dsh.tvdesk.news.app`）和 **stock-app.apk**（`com.dsh.tvdesk.stock.app`）
- 页面代码和插件版完全共用，只是宿主从桌面 Tab 换成 `HostActivity`
- 装完从电视应用列表直接启动，和插件版可同时安装
- 顶部留白从 96dp 收到 22dp；返回键先退到分类条，再按一次退出

## 2026-11-14 · v3.1.1：军事新闻日期 + 油价下次调价

同一天两个小修复，合并为一个版本发布。

**军事新闻日期**：新闻 → 军事（凤凰军事），右侧详情右下角只有 `凤凰军事`，没有发布时间。
军事分类没有 RSS，走网页抓取，`parseHtmlList()` 把时间写死成了空串。

- 解析列表页内嵌 JSON 的 `"url" … "newsTime"`，建立文章 id → 发布时间映射
- 轮播/推荐位等 JSON 里没有的条目，抓正文时从 `article:published_time` / `datePublished` 补
- 时间统一显示为 `11月14日 06:20`

**油价下次调价**：股票页 → 油价，右侧详情的「下次调价」在 11 月 14 日还显示 `11月12日`（上一次调价日）。
原来这个格子填的是 qiyoujiage 页面的**上次**调价日，真正算下次日期的代码是死代码。

- 改用 soyoujia 调价日历里「今天以后」的最近窗口（`2026-11-27`）
- 日历取不到时回退「上次调价 + 10 个工作日」
- 缓存过期时强制刷新；推不出未来日期显示「待公布」，不再把过去日期当未来
